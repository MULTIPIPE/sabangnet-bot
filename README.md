# 사방넷 발주 자동화 봇 (멀티파이프 잘잘잘)

스마트스토어·쿠팡 주문을 **사방넷 미니 → 사방넷 풀필먼트(3PL)** 로 넘기고, 송장을 다시 쇼핑몰로 보내는 과정을 윈도우 PC에서 자동으로 돌리는 프로그램입니다.

- 평일 **14:10** 발주: 미니 주문수집 → 주문확정 → 주문확인 → 풀필먼트 주문수집 → 출고요청
- 평일 **18:00** 송장: 풀필먼트 송장전송 → 미니 쇼핑몰운송장송신(스마트스토어·쿠팡에 송장 등록)
- 사람이 할 일: 처음 세팅 한 번. 그 뒤엔 PC만 켜져 있으면 됩니다.

> 베타 버전입니다. 처음 1~2주는 출고요청이 제대로 나갔는지 풀필먼트 화면에서 한 번씩 확인해 주세요.

---

## 1. 미리 준비할 것 (봇 설치 전)

| 순서 | 할 일 | 어디서 |
|---|---|---|
| 1 | 사방넷 미니 가입 (Starter 무료, 쇼핑몰 2개까지) | sbmini.co.kr |
| 2 | 미니에 스마트스토어·쿠팡 연결 | 미니 > 쇼핑몰관리 |
| 3 | **사방넷 클라이언트** 설치 (주문수집을 이 프로그램이 함) | 미니 우측 상단 사방넷 로고 > 클라이언트 설치 |
| 4 | 미니에 상품 등록 + 쇼핑몰 상품 ↔ 미니 품번·단품 매핑 | 미니 > 상품관리, 주문관리 > 품번/단품코드매핑관리 |
| 5 | 풀필먼트에 판매상품 등록 — **고유코드 = 미니 품번-단품** (예 `100002-0001`), 상품명 앞에 `[미니]`, 각 판매상품을 출고상품에 수량 1로 연결 | 풀필먼트 > 상품 |
| 6 | 풀필먼트 [쇼핑몰 주문수집 > 계정연결]에 내 미니 서비스코드가 연결돼 있는지 확인. 없으면 3PL 담당자에게 요청 | 풀필먼트 |
| 7 | 미니 [보안관리] 2단계 인증 = 사용함, [계정관리 > 미니사용자관리]에서 OTP 초기화 (봇이 구글 OTP를 직접 등록합니다) | 미니 |
| 8 | PC에 크롬 또는 엣지 설치 | — |

쇼핑몰 주문이 미니에 들어오고(주문서수집), 미니에서 확정하면 풀필먼트에 발주가 생기는 상태까지 **손으로 한 번 해보고** 봇을 켜세요. 봇은 그 손작업을 대신할 뿐입니다.

## 2. 설치

1. [Releases](../../releases/latest)에서 `사방넷봇.zip` 다운로드 → 압축 풀기 → `사방넷봇` 폴더가 생깁니다. 이 폴더를 `C:\사방넷봇` 처럼 **지우지 않을 곳**에 두세요. (설정·기록이 이 폴더 안에 쌓입니다)
2. `사방넷봇.exe` 더블클릭. 윈도우가 "PC 보호" 경고를 띄우면 **추가 정보 → 실행**. (서명 안 된 프로그램이라 뜨는 경고입니다)
3. 처음엔 본체(약 60MB)를 받느라 **1분 정도** 걸립니다. 창이 뜨면 설치 끝.

## 3. 처음 세팅 (5분)

1. **[계정] 탭**: 미니 아이디/비밀번호, 풀필먼트 회사코드/아이디/비밀번호 입력 → 저장. (이 PC 안에 암호화 저장, 어디로도 안 보냄)
2. **[상태] 탭 → [점검 실행]**: 미니·풀필먼트 로그인과 화면 구조를 확인합니다. 미니 2단계 인증이 뜨면 봇이 구글 OTP를 등록해 통과합니다. ✔ 가 다 나오면 정상.
3. **[설정] 탭 → 자동 실행 켜기**: 윈도우 로그인 시 자동 시작, 트레이 상주.
4. 봇을 처음 켠 시각이 **자동화 시작 시점**이 됩니다. 그 전 주문은 봇이 건드리지 않습니다 → 그 전 주문은 지금처럼 직접 처리하세요.

## 4. 운영

- PC가 **켜져 있고 잠자기 상태가 아니어야** 돕니다. 노트북은 덮개 닫힘/절전 끄기.
- 14:10~15:00 사이에 PC가 꺼져 있으면 그날 발주는 건너뛰고 알림만 뜹니다. 다음 평일에 밀린 주문까지 처리합니다. 급하면 [지금 발주 실행].
- 봇이 미니에 로그인하는 동안 내 크롬의 미니는 로그아웃됩니다 (동시접속 제한). 14:10, 18:00 몇 분만.
- 새 상품을 팔기 시작하면 **미니 단품 매핑과 풀필먼트 판매상품**을 먼저 만들어 두세요. 안 돼 있으면 봇은 "매핑 필요" 알림을 띄우고 그 주문은 건너뜁니다.
- 취소·교환·반품은 봇이 처리하지 않습니다. 지금처럼 직접.
- 당근·전화 주문 등 미니를 안 거치는 주문은 지금처럼 풀필먼트에 직접 발주하면 됩니다. 봇은 미니에서 넘어온 발주만 출고요청합니다.

## 5. 문제가 생기면

[상태] 탭 → **[로그 보내기]** → 바탕화면에 zip이 생깁니다. 그 파일을 카톡으로 보내주세요. (계정·비밀번호는 안 들어 있습니다)

## 6. 알아둘 것

- 이 프로그램은 사방넷 화면을 사람 대신 클릭하는 방식입니다. 사방넷 측 화면이 바뀌면 멈출 수 있고, 그때는 업데이트가 자동으로 내려갑니다 (10분마다 확인).
- 사방넷 약관상 자동화 도구 사용은 이용자 책임입니다. 계정 제한 등 불이익이 생길 수 있음을 알고 사용하세요.
- 무료로 제공되며, 사용으로 생긴 손해(오출고·미출고 등)에 대해 책임지지 않습니다. 출고요청 결과는 풀필먼트 화면에서 확인하세요.
